התקנה (פעם אחת לכל משתמש)

1. העלאה לאירוח: מעלים את כל הקבצים בתיקייה לאתר HTTPS סטטי
   (GitHub Pages / SharePoint / Azure Static Web Apps).
2. מחליפים בקובץ manifest.xml את YOUR-HOST בכתובת האתר.
3. מחליפים את logo.png בלוגו האמיתי (PNG, עדיף רקע שקוף).
4. כל משתמש: Outlook (Web / New Outlook) -> הודעה חדשה -> "..." -> Get Add-ins
   -> My add-ins -> Add a custom add-in -> Add from URL -> כתובת ה-manifest.xml

שימוש: מכינים מייל + נספחים, לוחצים על "סימן מים ICT" בסרגל, ושולחים.
